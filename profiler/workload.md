# Fixed 90-second workload

Start with the expanded Overview page and use one stopwatch for every run.

| Time | Action |
|---:|---|
| 0-30 s | Do nothing |
| 30 s | Right (Systems) |
| 35 s | Right (Projects) |
| 40 s | Right (Weather) |
| 45 s | Home |
| 50 s | F5 |
| 52 s | Space (collapse) |
| 57 s | Space (expand) |
| 62, 67, 72 s | Right through placeholder pages |
| 77 s | Home, then do nothing |
| 90 s | Press Ctrl+Q to close the application normally |

Do not kill Cage or the dashboard: qmlprofiler writes a complete trace only after a normal application exit.
